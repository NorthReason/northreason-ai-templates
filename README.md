# NorthReason AI Templates 🚀

Welcome to the official **NorthReason** AI templates repository! 

[NorthReason](https://northreason.com) is an AI-powered reasoning engine designed for modern developers. It converts natural language prompts into secure, production-ready WordPress plugins and Next.js/React components.

## 📦 What's Inside?
This repository contains a curated list of high-quality prompts and templates that you can use with NorthReason Studio to generate:
- Custom Gutenberg Blocks
- WooCommerce Integrations (Stripe, HubSpot, etc.)
- Next.js 14 App Router Components
- SaaS Dashboards and UI elements

## 🛠️ How to Use These Templates
1. Visit the [NorthReason Studio](https://northreason.com/studio).
2. Copy a prompt from our [Templates Directory](https://northreason.com/templates).
3. Paste the prompt into the Studio.
4. Generate, preview, and download your deployable `.zip` or `.tsx` files instantly!

## ⚡ Why NorthReason?
- **Security-First:** Automated verification for XSS and SQLi.
- **Architecture Planning:** It doesn't just generate code; it plans the file structure.
- **Dual Platform:** Seamlessly switch between WordPress PHP and React.
